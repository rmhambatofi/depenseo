# TRACEABILITY — exigences « M » → tâches → tests

Source : `docs/cahier-des-charges.md` révision 4. Périmètre : toutes les exigences fonctionnelles de priorité **M** (§4) et toutes les exigences non fonctionnelles de §7 (sans priorité, donc traitées comme M, ADR-008), hors volet web V2.
Chaque chemin cité doit exister : `node scripts/traceability.mjs` (lancé par `pnpm test` à la racine, P7-01) le vérifie ; un fichier à venir doit être suivi de « (Pn-nn… » où Pn-nn est sa tâche encore ouverte (marque à retirer quand la tâche est faite). Citer des chemins complets, sans motif. Le vérificateur ne contrôle que l'existence : le passage des tests est garanti par les suites complètes (`pnpm test`, `pnpm test:tz`, `flutter test`, Playwright) en CI.
Conventions : API `apps/api/test/**/*.spec.ts` (intégration contre MariaDB 10.6) ; shared `packages/shared/src/**/*.test.ts` ; mobile `mobile/test/**/*_test.dart`.
