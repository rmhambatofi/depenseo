# Depenseo

Application mobile de suivi et de contrôle des dépenses personnelles, pour la France puis l'Europe.

Depenseo suit uniquement les dépenses : pas de revenus, pas de comptes bancaires, pas de budget complet. À la place des revenus, chacun peut fixer une **limite de dépense** mensuelle ou hebdomadaire, facultative, et être alerté avant de la dépasser.
